COILWHINE — the one word an agent says when it has no idea what to do. Coil whine is the high-pitched noise hardware makes under load; when the agent stalls, the machine itself whines out loud, a physical noise as a confession. No explanation, no apology, no error report — just the sound its own body makes, shouted like a machine alarm.

## Run it

```sh
node main.ts
```

This writes exactly one word, `COILWHINE`, to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set). The program refuses to write anything that is not a single word of 1–99 characters.
